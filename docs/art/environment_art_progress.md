## Release and backup discipline

Keep readable planning updates and reviewed work-in-progress checkpoints committed to the existing art branch. Preserve original sources and versioned sealed candidate identities. Never overwrite a handed-off source path silently.

A package advances through source review, exact mechanical assembly, native actual-motion trial, independent visual/technical audit, target-branch integration and post-integration TEST/web verification. Test against the same snapshot and effective placement data. A failure produces a new version, not an edited seal with the same identity.

Owner previews show actual production-rendered motion for every motif, including quiet floor reflections and security motion. Use truthful named crops when necessary, with no preview-only brightness, timing or opacity boost. Keep attachments within the supported delivery size. A short excerpt plus explicit phase/wrap evidence is sufficient for long cycles.
