## Cold Continue release blocker

Actual package playtesting found a valid Storm Shelter save that restored its
HUD but displayed an empty room after a browser restart. The same captured save
reproduced the failure in the pinned Linux runtime. Persistence deliberately
omits the renderer snapshot, layout audit, and semantic projection, but the new
interaction preflight required all three before the trusted finalizers could
rebuild them.

The initial pass now authenticates durable geometry for a marked cold restore.
The normal scenario/world finalizers reconstruct derived projections, and the
complete strict proof remains mandatory before publishing the completed room.
Failed reconstruction restores the entry state and exposes no room geometry.
The captured-save regression restores the real machines, staff, exit, and
scenario props without changing cash, Heat, RNG, or time. A damaged durable
authority digest remains rejected. The regression is part of Smoke and the
automatically discovered Contract suite. Authored placement maps are unchanged.

## Packaged audio verification limitation

The legacy `postfix06_2_feature_pcm_runtime.ps1` expects a top-level `passed`
field that `PerfTelemetryOverlay.dump_report()` does not emit. Its Windows
allocator-plateau assertion also assumes a positive debug memory monitor;
Godot's official production Windows template reports zero for that monitor.
Those assertions cannot certify the current production report as written.

The independent release run therefore retains the actual per-boundary load,
play, cache-budget, and cleanup observations, and records unavailable production
allocator measurements explicitly. It does not treat zero as successful memory
evidence. The debug-engine soak measures allocator growth separately. Web's
actual heap/decoded-PCM measurements remain available and are checked against
their existing limits. See the final artifact-side verification report for
completed results and remaining limitations.
