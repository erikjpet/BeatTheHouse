# Beat the House 0.5.1 Release Checklist

Date: 2026-08-13
Status: RELEASED

## Purpose

0.5.1 is the immutable follow-up to the published 0.5.0 baseline. It folds the
post-release playtest branch and the final tutorial guardrail repair into one
clean patch without moving or replacing the existing `v0.5.0` tag.

## Included patch scope

- all committed changes from the `v0.5.0-playtest-fixes-8057bcc5` prerelease;
- durable tutorial frontier recovery after irregular actions, travel, modal
  interruption, queue loss, and save/load;
- Blackjack tutorial predicates that tolerate extra completed hands;
- mandatory DRINK PASS and CHIP SPILL controls on Pal's tutorial table,
  including in-place repair of already-stuck saves;
- exact Heat to Lookaway to Peek transition coverage across generated tables;
- corrected tutorial caught-Peek contract coverage before and after counting.

## Release decisions

- TUT-N17's five-cold-player sample was not completed. It remains an explicitly
  accepted playtest research limitation; no automated result is represented as
  a human trial.
- Scratch Ticket printed-well alignment is a separately scoped 0.6 art and
  geometry task. Crossword Corner still requires an owner choice before that
  prompt can execute.
- Android and iOS store publication remain outside this release. Their version
  metadata is updated, but signing and storefront work are not claimed.
- Itch publication requires a configured Butler installation/session and is
  separate from the final GitHub release.
