# Beat the House 0.5 trailer production

Revised 2026-07-26 from the Godot 4.6 project in
`D:\Projects\Beat-The-House`. The deliverables are a 30-second 16:9 gameplay
trailer, a 22-second vertical cut, and an 8-second silent page loop. Every
visual and sound comes from the project.

## Revision direction

The second edit responds to four specific quality problems in the original:

1. Full-screen synthetic cutaway art was not representative of the game.
   Feature copy is now rendered as a restrained transparent overlay on live
   gameplay. There are no standalone art cards in the trailer body.
2. Several shots held after their action had completed. Every trim now starts
   from a marker written by the deterministic Godot capture driver. The master,
   vertical cut, and loop contain no detected freeze longer than 0.85 seconds.
3. Blackjack made a visibly poor decision. The capture driver now reads the
   live total and the game's own basic-strategy recommendation. In the fixed
   capture it hits 9 to 18 and stands; in the Rourke hand it stands on 20.
4. The first music bed was too restrained. The replacement uses the game's
   Jazz Club generator at its authored peak layer, maximum-heat tempo target,
   bass, lead, and high/low drums. A clean 16-second in-engine phrase is looped
   on musical boundaries for the edit.

The structure retains gameplay-first guidance from
[Steamworks](https://partner.steamgames.com/doc/store/trailer?l=english) and
the genre → hook → content structure described by
[Derek Lieu](https://www.derek-lieu.com/blog/2021/4/12/game-trailer-structure-genre-hook-content),
but prioritizes motion and decision quality over feature-list completeness.

## Capture and edit implementation

- `tools/trailer_capture.gd` creates isolated, fixed-seed runs and writes a
  timing JSON file for every segment.
- Gameplay trims resolve marker names such as `action_roulette_spin_1`,
  `action_video_poker_draw_1`, and `duel_ready`; no capture timing depends on
  a guessed absolute offset.
- `tools/generate_trailer_cards.py` now emits transparent typography overlays
  only. It does not fabricate a background, casino floor, chip, or character.
- `tools/render_trailer.ps1` overlays copy on live gameplay, uses
  nearest-neighbor scaling, assembles the 30/22/8-second deliverables, and can
  separately skip captures or overlay regeneration.

Reproduce from source:

```powershell
Set-Location D:\Projects\Beat-The-House
.\tools\validate_project.ps1
.\tools\render_trailer.ps1 -Force
```

Reuse deterministic raw captures while rebuilding the edit:

```powershell
.\tools\render_trailer.ps1 -SkipCapture -Force
```

Reuse both captures and already-generated transparent overlays:

```powershell
.\tools\render_trailer.ps1 -SkipCapture -SkipCards -Force
```
