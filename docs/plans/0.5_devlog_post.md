# Beat the House 0.5.0 Devlog Post

Status: **DRAFT - 0.5.0 is not released.** Post only after final owner
playtest, final export packaging, uploads, and the release tag are complete.

## Title

Beat the House 0.5.0 - Grand Casino and UI Rebuild

## Body

0.5.0 is the biggest Beat the House cut since the last public release.

The most visible change is the Grand Casino. It is no longer just a finish-line
room; it now has connected casino spaces, a walkable Cage with Linda, chips,
Players Card claims, and a back-room showdown path that can turn into a
playable heads-up duel with Rourke.

The other big player-facing change is the interface. The HUD, room headers,
menus, popups, conversations, sale screens, and risky-action presentation have
all been rebuilt around the current game. The run clock is visible, pressure
is easier to read, and cheating now has its own dock instead of being buried
inside older action panels.

0.5.0 also adds Scratch Tickets as the eighth playable gambling surface.
Tickets are bought from scarce vending stock, lock their outcome at purchase,
and then reveal through scratch-off presentation. Collection bags now open
with a case-style reveal reel pinned to the item already granted, and Sal's
Pawn Shop can stock recovered finds on a resale shelf between runs.

Behind those headline features are a lot of release-queue fixes: onboarding,
the Cage gift shop tutorial, spatial inventory and item interaction cleanup,
multi-person conversations, event popup polish, web travel/audio fixes, and
input hardening from playtest.

Beat the House remains simulated gambling only: no real-money wagering, no
cash prizes, and no gambling monetization.

## Feature List

- Expanded Grand Casino endgame with connected rooms, Cage services, chip
  economy, Players Card claims, and Rourke duel.
- Scratch Tickets added as the eighth playable game.
- Complete UI redesign: HUD, room headers, cheat dock, popups, conversations,
  menus, sale screens, and run report polish.
- Sal's Pawn Shop resale shelf for recovered finds.
- Collection bag reveal reel pinned to the already-granted item.
- Spatial inventory and item-interaction renovation.
- Onboarding and Cage gift shop tutorial updates.
- Conversation/event polish, including multi-person lenders and Crew group
  conversations.
- Web and input stability fixes from the 0.5 prerelease queue.
