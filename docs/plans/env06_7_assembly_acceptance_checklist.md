Status: fixed before package implementation

does not rewrite package content to make a gate green.

- [ ] Package A contains exactly Corner Store (5), Back Alley (4), Pawn Shop
  (3): 12 ids.
- [ ] Package B contains exactly Motel (4), Gas-Station Casino (5), Beach (3):
  12 ids.
- [ ] Package C contains exactly Bar (7), Jazz Club (4): 11 ids.

  12 ids.
- [ ] Package E contains exactly Delta Queen (5), Grand Casino (3): 8 ids.
- [ ] All 55 established ids appear exactly once. No archetype, file, dossier,
  test, capture, weight, or rumor anchor is silently omitted or double-owned.
- [ ] Every package arrives at an exact independently reviewed head with base,

## Shared catalog assembly

- [ ] The assembly owner is the sole editor of shared catalog indexes/loaders,
  cross-catalog dossier/report files, and any monolithic scenario catalog.
- [ ] Package payloads are extracted by exact net diff. Behind or entangled
  branches are not merged wholesale.
- [ ] Stable ids, weights, selection/reachability, rumor anchors, compatible
  consequences, refs, and legacy save identity survive assembly.
- [ ] Shared adapters remain neutral and bounded. No scenario-id switch or
  archetype-specific branch is added to env06_6 runtime code.
- [ ] Cross-package conflicts in semantic ids, handlers, routes, actors,
  services, games, and assets are resolved through declared namespaces and
  ownership, not silent renaming that breaks saves.

## Cross-catalog anti-cloning and completeness

- [ ] A machine-readable report contains 55/55 dossiers with nonempty
  implementation, tests, complete graph, outcomes, persistence, signatures,
  seeds, and capture sets.
- [ ] Global pairwise signature comparison has zero equivalent complete
  verb->phase->aftermath sequences, including across archetypes/packages.
- [ ] Nearest-neighbor findings demonstrate distinct pressure, second verb,
  world connection, branch topology, and aftermath when primitives are shared.
- [ ] One contact sheet per archetype shows every arrival and every terminal
  aftermath without title/sign dependence; independent reviewers can identify
  each variant by room state.
- [ ] Every id is seed-reachable and every phase/branch fixture-reachable. No
  established selection weight is altered merely to produce evidence.
- [ ] Composition covers base service + game + event + traveler + sweep,
  package-specific conflicts, and mid-game scenario response. Base functionality
  survives cleanup/expiry.
- [ ] Save/load at every phase/branch and partial/terminal revisit passes for
  all 55 with exact semantic snapshots and no duplicate consequence.

## Gate Service and final review

- [ ] One exact assembly head is bound to Godot identity, native-plugin path and
  SHA-256, commands, timeout/method, durations, exit codes, complete streams,
  report hashes, host/date, and first results.
- [ ] Project validation; relevant content/systems/UI/save/accessibility/full
  Foundation suites; env sequence/uniqueness audit; 10-seed determinism;
  native/Web parity; performance/liveness; and visual QA all pass.
- [ ] Content/privacy/Voice Bible checks report zero unknown refs, hidden leaks,
  orphan objects/hit regions, unsafe executable refs, overlaps, clipping, stale
  targets, unreachable interactions, or unsafe exits.
- [ ] Performance proves boundary-prepared state, no per-frame schema/rebuild/
  deep-copy work, and nonzero advancing idle liveness.
- [ ] Every red/timeout/repeat is retained. No test weakening, filtered failure,
  automatic golden refresh, selective rerun, or budget increase is accepted.
- [ ] Final independent review checks the exact assembly head against the full
  row prompt, common checklist, five package checklists, and this checklist.

Only the complete 55-id assembly can receive `ACCEPT <exact-head>`. Package
acceptance is an intake decision, not completion of `env06_7`.
