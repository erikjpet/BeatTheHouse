0.6.1 to stability, bug fixes, issues found through playtesting, and measured
performance improvements. The accepted 0.6 placements remain the baseline;
change them only for a reproduced usability problem or owner feedback.

The official 0.6 baseline is tag `v0.6.0`, source
`a095414b20cdb3570e06b367c621be43e0256109`. Main's subsequent README change
`395990c` does not change the game. Keep the published tag and assets immutable.
The older [deferral inventory](0.6.1_backlog.md) is historical context: its art,
new content, balance redesign, Steam and mobile work is outside this release.
