# 0.5 UI Art Manifest

This is the artist handoff and runtime contract for every PNG under
`assets/art/ui/`. All new 0.5 assets are loaded through
`scripts/ui/ui_art.gd`; a missing icon, portrait, or environment title
therefore produces a token-colored code fallback instead of a broken
texture. PNGs use nearest-neighbor filtering and transparent backgrounds.

The source atlas exports are reproducible with
`tools/generate_ui05_art.py`. `assets/art/ui/source_index.json` records
the ordered crop map. Generated source atlases were approved specifically
for this pass; the exported PNGs are the editable runtime handoff.

## Replacement workflow

Keep the path, canvas dimensions, alpha channel, and semantic silhouette.
Replace only the PNG; do not add loader branches. Run
`tools/ui05_asset_pipeline_check.ps1` after replacement. The check
cross-references this manifest with the filesystem and temporarily moves
one title and one icon to prove both fallback paths still load.
