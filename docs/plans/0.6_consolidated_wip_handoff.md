# 0.6 Consolidated WIP Handoff

Status: WIP — intentionally not part of `main`

superseded, experimental, and locally recovered 0.6 work. Its history joins
every former local and GitHub feature-branch tip so the old branches can be
removed without losing their commits.

WIP is retained through the consolidation merge parents and is indexed in
`0.6_consolidated_branch_manifest.tsv`. Recover a former line by locating its
recorded head and inspecting or cherry-picking only the required commits.

## Recovery rule

Do not merge this branch wholesale into `main`. Start new work from `main`, use
the manifest to find the relevant historical head, extract the smallest valid
change, verify it against current `main`, and merge that completed change into
`main` before updating this handoff.
