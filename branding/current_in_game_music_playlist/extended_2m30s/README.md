# Extended Current In-Game Music Playlist

This folder contains 2:30 versions of all 20 tracks in the parent current
in-game music playlist.

Open `extended_playlist.m3u8` in a playlist-capable audio player to hear the
complete extended set in order.

Each version repeats its complete source master at the exact WAV frame boundary,
is trimmed to exactly 2 minutes 30 seconds, and fades over the final 0.5 seconds
for a clean ending. The source mix, 44.1 kHz sample rate, mono channel layout,
and 16-bit PCM format are preserved.

See `extended_playlist_manifest.json` for source durations and repeat details.
