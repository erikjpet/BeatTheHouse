# Art Rework Test 11 — Reimagined Day / Restored Test 04 Night

This set resets the direction after Test 10.

## Nighttime

The 18 midnight images are untouched, byte-identical copies of the approved Test 04 environments. They retain the dark neon Miami night appearance.

## Daytime

The 18 noon images are newly generated paintings of the same recognizable spaces. They are not palette shifts, lookup-table conversions or brightened versions of the night gradients.

Each daytime image uses:

- its Test 04 night scene as the composition and feature reference;
- the approved `calibration_refs` as the daylight quality reference;
- unrestricted local object and material color;
- natural daylight, blue sky, wood, stone, glass, greenery, coral, fabric and metal as appropriate to the scene;
- the same major architecture, openings, object footprints, gameplay areas and overlay locations as its night counterpart.

The daytime rendering is intentionally a full repaint, so fine pixels and lighting details do not match the night image one for one. Scene identity and functional layout—not night-palette geometry—are the invariants for this direction.

## Folders

- `noon/` — game-size 900 × 430 daytime images.
- `noon_full_resolution/` — original generated daytime masters.
- `midnight/` — restored 900 × 430 Test 04 night images.
- `calibration_refs/` — approved daytime appearance references.
- `day_night_contact_sheet.png` — paired overview.
- `noon_contact_sheet.png` — daytime overview.
- `generation_brief.md` — shared art-generation direction.
- `transition_plan.md` — revised plan for transitions between independently painted endpoints.

No production game files were overwritten.
