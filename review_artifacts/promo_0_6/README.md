# Retained 0.6 promotional source captures

These 23 files are the completed capture working set preserved in
`561f1dea838bd6413933ff7cf68c330d77c3104e`. They support the editable social
poster in `branding/social/0.6.0_devlog_6_promotional_post.svg` and retain
additional visual references for later promotional work.

The directory and filenames retain their original `current` names so the SVG
references remain portable. They describe the earlier promotional capture
session, not the latest `main` build. An exact source commit was not recorded in
the capture reports; do not infer one from the later preservation commit.

`current_scenarios/report.json` retains its original per-scene results,
including failed layout checks. `current_coin_pusher/manifest.json` retains its
original visual-capture observations. These are historical capture metadata,
not current test expectations or release certification. No result or hash was
refreshed when the files graduated from WIP.

The poster PNG, editable SVG, caption, alt text, background, and gameplay
captures are repository source material. Retaining them does not post the
caption, publish the poster, or replace the official 0.6 tag or package assets.
