# Art Rework Test 01

This folder is an isolated visual-direction test. Nothing here is wired into the game or replaces production art.

## Direction

An original retro coastal casino look built from crisp geometric forms, saturated cobalt/coral/ivory color, hard sunlight, calm resort architecture, and polished poster-like compositions. The work intentionally avoids copying any individual artist.

## Suggested feedback

For each group, note:

1. What feels right?
2. What feels wrong?
3. Should the next pass be flatter or more dimensional?
4. Should the palette be brighter, darker, warmer, or cooler?
5. Which single asset should become the reference target for the next round?

The exact generation briefs are recorded in `prompts.md`.
