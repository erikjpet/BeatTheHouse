# Standard travel vehicle generation

Generated on 2026-11-11 with the built-in image_gen tool, transparent_background=true. No API or CLI fallback was used. Inspected the existing assets/art/travel/back_alley_bar/bus_arrival.png and street_strip.png before design. Those approved pixels informed the chunky dark neon style; they were not modified and were not supplied as editing targets.
